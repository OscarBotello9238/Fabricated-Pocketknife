# Fabricated-Pocketknife
This repository shows the complete design and manufacturing process of a custom pocketknife. I used manual machining, waterjet cutting, 3D printing, investment casting, and other fabrication methods to create a functional final product.
This project taught me early on that a design working in CAD does not always mean it will be easy or affordable to manufacture. It pushed me to think beyond the design and focus on practical problem-solving, efficiency, and manufacturability. 



The repository includes CAD models, photos, and videos documenting the process.
